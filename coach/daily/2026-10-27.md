### 1. Remove Duplicates from Sorted Array · LC 26 · Easy
`Two Pointers`  ·  <https://leetcode.com/problems/remove-duplicates-from-sorted-array/>

**中文切入**：数组已排序，重复元素相邻。慢指针 write 指向下一个可写位置，快指针 read 扫描；只有 nums[read] != nums[write-1] 时才写入。

**面试英文（照这个说）**：Since the array is sorted, duplicates are adjacent. I keep a write pointer for the next unique slot and scan with a read pointer, copying a value over only when it differs from the last written one. That gives O(n) time and O(1) extra space.

**复杂度**：O(n) time / O(1) space

**⚠️ 易错**：返回的是新长度 k，不是数组本身；比较对象是 nums[write-1] 而不是 nums[read-1]。

### 2. Rotate Array · LC 189 · Medium
`Reverse Trick`  ·  <https://leetcode.com/problems/rotate-array/>

**中文切入**：整体反转 + 前 k 个反转 + 后 n-k 个反转，三步到位；k 先对 n 取模。

**面试英文（照这个说）**：I rotate in place with three reversals: reverse the whole array, then reverse the first k elements, then reverse the rest. Each element moves exactly once, so it is O(n) time and O(1) space.

**复杂度**：O(n) time / O(1) space

**⚠️ 易错**：k 可能大于 n，先 k %= n；k == 0 直接返回。

### 3. Sort Colors · LC 75 · Medium
`Dutch National Flag`  ·  <https://leetcode.com/problems/sort-colors/>

**中文切入**：三指针 low / mid / high：low 左边全是 0，high 右边全是 2，mid 扫描未知区。遇到 0 与 low 交换，遇到 2 与 high 交换。

**面试英文（照这个说）**：This is the Dutch national flag problem. Everything before low is 0, everything after high is 2, and mid scans the unknown region. Swapping with high does not advance mid because the incoming value is still unclassified.

**复杂度**：O(n) time / O(1) space

**⚠️ 易错**：与 high 交换后 mid 不能自增；循环条件是 mid <= high。

### 4. Majority Element · LC 169 · Easy
`Boyer-Moore Voting`  ·  <https://leetcode.com/problems/majority-element/>

**中文切入**：摩尔投票：维护候选数和计数器，遇到相同就 ++，不同就 --，归零就换候选。出现次数过半的数最后一定留在候选位。

**面试英文（照这个说）**：I use Boyer-Moore voting: keep a candidate and a counter, decrement on mismatch and reset the candidate at zero. The majority element survives because it outnumbers all other elements combined.

**复杂度**：O(n) time / O(1) space

**⚠️ 易错**：题目保证多数元素存在；若不保证，需要第二遍验证候选数出现次数。

### 5. Next Permutation · LC 31 · Medium
`Array Manipulation`  ·  <https://leetcode.com/problems/next-permutation/>

**中文切入**：从右往左找第一个下降点 i（nums[i] < nums[i+1]），再从右找第一个大于 nums[i] 的 j，交换后反转 i+1 到末尾。

**面试英文（照这个说）**：I find the rightmost index i where nums[i] is less than nums[i+1], then the rightmost j whose value is greater than nums[i], swap them, and reverse the suffix. The suffix is decreasing, so reversing it yields the smallest next arrangement.

**复杂度**：O(n) time / O(1) space

**⚠️ 易错**：完全降序时 i 找不到，直接反转整个数组得到最小排列。
