## 🆕 新题

### 1. Rotate Image · LC 48 · Medium
`Matrix`  ·  <https://leetcode.com/problems/rotate-image/>

**中文切入**：顺时针 90° = 先沿主对角线转置，再左右翻转每一行；或者按层做四点轮换。

**面试英文（照这个说）**：A clockwise 90-degree rotation equals a transpose followed by reversing each row. I swap (i, j) with (j, i) over the upper triangle, then reverse every row, which is O(n^2) time and O(1) space.

**复杂度**：O(n^2) time / O(1) space

**⚠️ 易错**：转置只遍历上三角；逆时针是转置 + 上下翻转，注意方向。

### 2. Set Matrix Zeroes · LC 73 · Medium
`In-place Marking`  ·  <https://leetcode.com/problems/set-matrix-zeroes/>

**中文切入**：用第一行和第一列当作标记位，另外用两个布尔量记录第一行/第一列本身是否要清零。

**面试英文（照这个说）**：I use the first row and first column as marker arrays instead of allocating new ones, plus two booleans for whether those lines themselves must be zeroed. Then I clear cells in a second pass, keeping it O(1) space.

**复杂度**：O(mn) time / O(1) space

**⚠️ 易错**：第二遍清零要从右下往左上走，否则标记位会被提前覆盖。

### 3. First Missing Positive · LC 41 · Hard
`Index as Hash`  ·  <https://leetcode.com/problems/first-missing-positive/>

**中文切入**：答案一定在 1..n+1 之间。把值 v 交换到下标 v-1 的位置（cyclic sort），再扫一遍找第一个 nums[i] != i+1。

**面试英文（照这个说）**：The answer must lie in 1 to n+1, so I place each value v at index v-1 by swapping until every value is home or out of range. Then the first index that does not hold i+1 is the answer, all in O(n) time and O(1) space.

**复杂度**：O(n) time / O(1) space

**⚠️ 易错**：用 while 交换，且条件写成 nums[i] != nums[nums[i]-1]，否则会死循环。
